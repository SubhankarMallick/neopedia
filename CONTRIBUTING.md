# How to contribute to our cause?

To contribute to our cause, you may do the following - 

- Contact Subhankar Mallick in person (if you know him) for helping to create the articles for the website or help develop the backend.

- Raise an issue on [GitHub](https://github.com/SubhankarMallick/neopedia/issues) if you notice any mistakes/typos in the content.

## Suggestions

Use any markdown formatting app like Obsidian, MarkText or any other app that has LaTeX support. If you are confident, you may use any text editor, however these apps will provide the smoothest experience.
